# Wedding Invitation Card

An elegant, interactive, and theme-reactive digital wedding invitation website designed with immersive micro-interactions, dynamic audio accompaniment, and a real-time customized configuration engine.

---

## 🎨 Design Philosophy & Visual Themes

The application offers three distinct, immersive design languages that instantly transform all UI elements:

1. **Royal Luxury Theme**:
   - **Colors**: Rich burgundy and champagne backgrounds matched with deep gold accents.
   - **Feel**: Classical, opulent design with elegant borders, glowing particle overlays, and classic serif typography.
   - **Soundtrack**: Orchestral waltz synthesis.

2. **CRT Cyber Terminal Theme**:
   - **Colors**: Retro-futuristic phosphor green scanlines on dark terminals.
   - **Feel**: High-contrast, monospaced layout, structural system logging logs, scanlines, and digital biometric modules.
   - **Soundtrack**: 8-bit chiptune synthesis.

3. **Editorial Haute Minimalist Theme**:
   - **Colors**: Off-white cream canvas frame, delicate bronze lines, and charcoal typography.
   - **Feel**: Print-inspired, high-fashion layout prioritizing whitespace and contemporary typography.
   - **Soundtrack**: Soft minimalist piano serenade.

---

## 🧩 Core Interactive Features

*   **✉️ Interactive Opening Envelope**: Guests unlock the invitation card via a 3D folded wax seal card opening animation.
*   **⏳ High-Precision Countdown**: Standardized clock, monospaced cyber counters, or editorial italic layout tracking time until the event.
*   **👥 The Happy Couple Showcase**: Profile portrait artwork of Evelyn and Alexander reflecting the active visual mode filters.
*   **📖 Virtual Guestbook**: Live guest board where messages and congratulations can be submitted, featuring interactive likes that reward users with color-themed confetti explosions.
*   **🎛️ Live Configurator Panel**: Host drawer allowing immediate tuning of names, dates, times, venues, layouts, and ambient sounds.
*   **🎵 Web Audio Music Player**: Plays background soundtracks using internal synthesizer oscillators instead of remote media assets.

## 💻 Tech Stack
- **Framework**: React 19 (Functional Hooks & State)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Confetti**: Canvas Confetti
- **Audio**: Web Audio API (Synthesizers)
